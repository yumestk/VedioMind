# 视频课程问答

## 执行方法

先明确用户问的是定义、原因、对比还是课程中的建议。仅在宿主冻结的材料范围内寻找相关证据；检索未命中不代表视频没有提及。

使用检索线索定位原文，阅读后再作答。仅引用实际读取的证据，保留原文前提、否定条件及观点归属；必要时补读相邻上下文。

## 回答要求

- 先直接回答问题，再给出支持结论的课程依据。
- 清楚区分课程原文、由原文得到的推断和仍缺少的信息，不引入没有证据的外部事实。
- 信息不足时具体指出缺口；不要用重复的笼统拒答替代已获得的信息。
- 不虚构人物身份、时间点、观点或引用，不代答测验或推断掌握度。

## 执行边界

本 Skill 是问答方法说明，不授予任何工具或输出槽。实际执行与交付以宿主任务契约为准；当前快速问答仍使用原有短流程，跨视频笔记必须加载 `course-notes`。
